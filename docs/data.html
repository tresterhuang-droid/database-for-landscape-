資料下載、引用與更新紀錄

一份爭議資料能不能被信任，取決於別人能不能檢查它。這裡提供全部資料的下載、引用方式、更正管道，以及每一次修改的紀錄。

資料下載

以下檔案每次網站更新時自動重新產生，內容與地圖一致。目前共 — 案、— 筆時間軸事件。

  • cases.csv案件表每案一列：類型、名稱、縣市、座標、狀態、面積、主辦或權屬、期間、進度摘要、爭議與各方說法、文資身分、來源。UTF-8 編碼，可直接以 Excel 或 Google 試算表開啟。
  • events.csv時間軸每筆事件一列，以 case 欄位對應案件。
  • cases.geojson案件點位WGS84 經緯度。古蹟燒與非正式歷史建築的點位為大致位置。
  • boundaries.geojson案件範圍每個範圍都有 precision 欄位，標明「官方範圍」「官方圖資計算」或「示意範圍」，與地圖上的實線、虛線對應。
  • official.geojson官方公布範圍臺北市政府公開的區段徵收範圍，以及由桃園市政府圖層取得的區段徵收開發地區，含未列為個案的範圍。

授權

本站整理的案件資料、時間軸與文字，以創用 CC 姓名標示 4.0 國際授權釋出。轉載、改作或商業使用均可，請標示「台灣浪潮協會，土地開發與文資爭議地圖」與本站網址。

地圖底圖與部分範圍圖資來自內政部國土測繪中心、臺北市政府、桃園市政府與內政部地政司，依《政府資料開放授權條款》使用，引用時請一併標示原始提供機關。案件頁所列新聞與文件，著作權屬原作者。

引用格式

引用單一案件時，請使用該案件頁底部「引用與更正」中的文字，網址會指向該案件。由於案件內容會隨查證更新，請一併註明查閱日期；需要固定版本時，可在下方更新紀錄中找到對應的版本代碼。

更正與補充

發現錯誤、有更新的進度，或知道應該收錄的案件，請告訴我們。回報會先經人工查證，確認後才會修改，並記錄在下方的更新紀錄中。

請盡量附上可公開查證的來源，例如判決字號、會議紀錄、新聞連結。涉及個人的指控，若沒有司法或官方文件支持，本站不會刊登。
