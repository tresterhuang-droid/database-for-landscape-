收錄方法與選擇漏斗

一張爭議地圖最容易被誤讀的地方，在於它沒有畫出來的東西。這一頁交代五類案件各自從哪個母體出發、經過哪些門檻才被放上地圖，也列出目前還做不到、或刻意不做的部分。

本頁目錄
  1. 為什麼把五類放在同一張地圖
  2. 共同的選擇漏斗
  3. 各類型的母體、門檻與排除
  4. 點位、範圍與資料精度
  5. 目前的收錄數量與縣市覆蓋
  6. 未盡事項

為什麼把五類放在同一張地圖

區段徵收、市地重劃與都市更新，是台灣重組都市土地的三種主要制度。三者的法律結構不同：區段徵收由政府取得全區所有權再發還一部分；市地重劃讓地主保有產權，以土地折抵開發成本；都市更新則在既有建物與產權上重建。三種制度卻共用同一個前提：只要達到法定比例或經過核定，不同意的人也必須參與。

古蹟燒與非正式歷史建築，處理的是另一個層面。土地重新配置時，原本附著在土地上的建物與記憶，有些取得了文化資產身分，有些沒有；有身分的可能失火，沒有身分的可能在審議空窗期被拆除。把這兩類放進來，是為了讓「開發」與「保存」在同一張圖上對照，而不是把兩件事分開討論。

這樣的並置是一種編輯判斷，不代表五類案件性質相同，也不代表每件文資火災都與開發有關。各案的起火原因、開發動機，一律以官方鑑定、判決或可查證的報導為準。

共同的選擇漏斗

每一類案件都經過下面五道篩選。前兩道決定「可能被收錄的範圍」，後三道決定「實際被放上地圖的案件」。

  1. 母體能找到的最完整清單或資料來源，例如內政部地政司的區段徵收統計、文化資產火災列表。母體本身若不完整，會在各類型說明中標出。
  2. 時間與地理範圍台灣本島與澎湖、金門、馬祖。區段徵收、市地重劃、都市更新不限年代，但優先收錄仍在進行或影響仍持續的案件；古蹟燒限近20年（2006年起）。
  3. 爭議門檻至少符合一項：進入行政或司法爭訟、監察院調查、刑事追訴；發生強制拆除、迫遷或持續的自救會行動；文資審議結果與調查研究或社會主張明顯分歧；或在制度史上具指標性，例如促成大法官解釋或修法。
  4. 可查證門檻至少一個可公開連結的來源，能確認時間、地點與基本事實。只有社群貼文、未經查證的指控，暫不收錄。說法互相矛盾時並列，不代為裁決。
  5. 代表性取捨同一類型中，優先收錄能說明不同制度問題的案件，並盡量讓每個縣市都有案例；不以案件數量多寡作為縣市之間的比較。

各類型的母體、門檻與排除

區段徵收

母體
內政部地政司「全國已公告區段徵收案件統計」150案（至2025年），加上尚未公告徵收、仍在都市計畫或土地徵收審議階段的案件，如社子島、台知園區、竹科三期。
收錄門檻
符合共同爭議門檻者，以及「制度原型」案件：五個高鐵站區特定區雖然爭議較低，卻是區段徵收被大規模用於站區開發的起點，因此收錄作為對照。
不收錄
已完成多年、查無公開爭議的一般案件。這些案件仍列在首頁「全國有多少區段徵收」的完整清單中，只是沒有個別案件頁。
範圍圖
台北市20處使用市府公開的官方範圍；航空城以桃園市政府圖層計算；八處高鐵站區等以地段圖描繪「示意範圍」。

市地重劃

母體
各縣市地政局公告的公辦與自辦市地重劃區。全國沒有一份整合、可下載的重劃區爭議清單，因此母體是以各縣市地政局資料、判決系統與新聞交叉建立，不完整。
收錄門檻
共同爭議門檻之外，特別關注自辦市地重劃：大法官釋字第739號（2016）已認定相關程序規定違憲，近年台中、台南、高雄仍有多起涉及同意比例、理監事選任、人頭地主或刑事賄賂的案件。
不收錄
農地重劃、農村社區土地重劃（法律基礎與市地重劃不同）；只有地價或房市討論、沒有權利爭議的重劃區。
界線說明
塭仔圳在制度上是公辦市地重劃，不是區段徵收；它的迫遷爭議與區段徵收相近，因此歸入本類，並在案件頁說明兩種制度的差異。

都市更新

母體
各直轄市與縣市核定的都市更新事業計畫，數量以千計。本站只從中篩出爭議案件。
收錄門檻
不同意戶遭強制拆除或代為拆除；行政法院撤銷核定；產權不清導致住戶在程序中失去權利；或都更與文資保存直接衝突。
不收錄
一般「危老重建」案件，除非與文資保存衝突；只涉及建商與同意戶之間分配糾紛、未進入公共討論的案件。
界線說明
都更與文資衝突的案件，若建物曾受列冊追蹤或提報，會依「主要爭點」歸類：溫州街52巷歸都市更新，臺灣拓殖株式會社穀倉歸非正式歷史建築。兩案在各自頁面互相提及。

古蹟燒（文資火災）

名稱
「古蹟燒」是社會上對文資建物反覆失火的通稱，帶有懷疑人為的語氣。本站沿用這個名稱，是因為它指出的現象確實存在：失火常發生在保存爭議或開發壓力最高的時刻。但本站不據此推定任何個案的起火原因；原因一律以消防鑑定、判決或主管機關說明為準，說法不一時並列。
母體
維基百科「臺灣文化資產火災列表」作為索引，再逐案回到新聞、消防局或文化主管機關資料查證；並參考文化部歷年統計。
時間範圍
2006年至今（近20年）。
收錄門檻
火災時具法定文資身分（古蹟、歷史建築、紀念建築、聚落建築群、文化景觀），或已列冊追蹤、提報審議、具公開文資價值主張的建物；且火災造成主體受損。重複起火、與拆遷或開發同時發生、或暴露管理缺口的案件優先。
不收錄
僅附屬設施輕微受損、當日即撲滅且無後續保存影響的小型火警。

非正式歷史建築

定義
具有公開的文資價值主張，但未取得、或已失去文化資產法定身分的建物。包括：文資審議「不指定、不登錄」；列冊追蹤後解除；暫定古蹟遭撤銷；登錄後遭廢止。「非正式」指的是法律身分，不是價值高低。
母體
沒有官方清單。依定義，這一類的母體就是官方系統之外的東西，只能從文資審議紀錄、文史團體提報、監察院調查與新聞中逐案建立，必然有大量黑數。
收錄門檻
已遭拆除或焚毀，或正面臨拆除；且至少有一項可查證的價值主張（調查研究、提報紀錄、審議紀錄、專業團體公開聲明）。
縣市覆蓋
目標是每個縣市至少一案，以避免地圖只反映北部媒體的注意力。目前尚未達成，缺漏縣市列於下方表格。
不收錄
單純屋齡老、但沒有任何公開價值主張或保存行動的建物。

點位、範圍與資料精度

地圖上的形狀代表類型：圓點為區段徵收，方塊為市地重劃，菱形為都市更新，三角為古蹟燒，空心環為非正式歷史建築。顏色代表狀態。區段徵收的圓點大小對應面積；其他類型面積差異太大或不適用，以固定大小呈現。

官方範圍
政府公開的向量圖資，實線呈現。
官方圖資計算
由政府圖層運算得出，例如航空城以桃園市政府「特定區計畫範圍」扣除「剔除區段徵收地區」。實線呈現，案件頁說明算法。
示意範圍
依國土測繪中心地段圖中「區段徵收」類別的地段描繪，虛線呈現，並與公告面積對照。
點位
沒有範圍圖的案件只標點。古蹟燒與非正式歷史建築多為單棟建物，點位為大致位置，不應作為地籍或門牌依據。

未盡事項

  • 縣市覆蓋不均。新類型的第一批案件集中在台北與台中，東部、離島與多數縣的市地重劃、都市更新、非正式歷史建築尚未收錄。這反映的是媒體與文史團體注意力的分布，也反映本站的查證能力，不是各地案件多寡的比較。
  • 古蹟燒尚未完整盤點近20年。第一批11案是依代表性挑選，尚未逐筆比對火災列表與文化部統計。下一步是建立2006年以來的完整清單，再依門檻篩選。
  • 部分事實待核。彰化南郭郡守官舍群火災的年份、拓殖株式會社穀倉的拆除年份、台中刑務所官舍群與陽明山美軍宿舍的修復情形，案件頁已標「待核」或「待補」。
  • 市地重劃與都市更新缺少全國母體。自辦重劃的爭議多散落在判決系統；都更爭議以台北最多報導，新北、高雄等地的案件需要逐一從判決與地方新聞補齊。
  • 新類型沒有範圍圖。目前只以點位呈現。重劃區範圍可從各縣市地政局的重劃區圖取得，將陸續補上。
  • 時間軸較簡略。新類型的時間軸只記錄關鍵節點，部分事件尚未附上個別來源連結，來源列於案件頁底部。
  • 「浪潮觀點」只有區段徵收的三則草稿。新類型尚未撰寫評析；事實層與觀點層會持續分開標示。
  • 爭議門檻帶有編輯判斷。什麼算「具指標性」、什麼算「公開的價值主張」，無法完全量化。本站把判斷依據寫在每案的「爭議與各方說法」中，歡迎指正與補充。
  • 不收錄的界線仍在討論。例如塭仔圳這類爭議性質接近區段徵收的市地重劃、華光社區這類以國土活化為名的迫遷，都需要在類型之間做歸類決定。歸類方式若有調整，會在本頁更新。
